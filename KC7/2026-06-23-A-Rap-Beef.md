A Rap Beef: An Intro to Security Investigations

Date: 23 June 2026
Platform: KC7
Category: Security Investigation | Kusto Query Language (KQL)

Objective

To complete my first guided security investigation using Kusto Query Language (KQL) and understand how different security logs are used to investigate an incident.

What I Did

- Completed the guided investigation in KC7.
- Explored the available log tables using KQL.
- Followed the investigation step by step by analyzing the available evidence.
- Learned how information from one type of log can be used to continue an investigation in another log source.

New Things I Learned

- Different log sources provide different pieces of information during an investigation.
- Email events can serve as the starting point for an investigation.
- Authentication events help identify user sign-in activity.
- Outbound network events help reveal connections made from a device to external systems.
- Inbound network events provide visibility into incoming network connections.
- A security investigation often involves correlating information from multiple log sources rather than relying on a single event.

KQL Concepts Practiced

- Exploring log tables
- Reading query results
- Understanding log fields

Reflection

This was my first experience using Kusto Query Language (KQL) in a security investigation. The lab introduced me to how KQL can be used to explore and analyze security logs. It also gave me a better understanding of how security analysts use evidence from multiple data sources to investigate incidents.
